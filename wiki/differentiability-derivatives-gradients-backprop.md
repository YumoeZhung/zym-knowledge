# 可导、偏导、方向导数与可微：梯度何时能描述局部变化

最容易混淆的地方是把“某些方向能够算出斜率”和“存在一个梯度统一解释所有局部变化”当成同一件事。前者对应偏导数或方向导数，后者才是多元函数可微的核心。

## 一元函数：可导与可微通常等价

对于一元函数 `y=f(x)`，在一点可导表示极限

```text
f'(x) = lim[h->0] (f(x+h)-f(x))/h
```

存在。在一元情形中，“在该点可导”和“在该点可微”通常等价，因此日常可以近似理解为：

```text
不可导 ≈ 不可微
```

例如 `f(x)=|x|` 在 `x=0` 的左右导数不同，所以在该点不可导，也不可微。

## 多元函数：先区分三层概念

设损失函数依赖多个参数：

```text
L = f(theta_1, theta_2, ..., theta_n)
```

| 概念 | 检查什么 | 直觉 |
|---|---|---|
| 偏导数 | 只改变一个坐标参数 | 只沿东西或南北方向测坡度 |
| 方向导数 | 沿指定向量同时改变若干参数 | 沿指定道路测坡度 |
| 可微 | 是否存在一个统一的线性近似 | 能否用同一块切平面解释所有方向 |

因此，“可导只看一个方向、可微看所有方向”可以作为初步直觉，但更准确的说法是：

> 偏导数和方向导数分别检查某个方向；可微要求所有方向的局部变化由同一个线性映射统一解释。

## 可微真正保证了什么

函数在 `theta` 处可微，意味着存在一个线性映射 `L`，使得：

```text
f(theta + delta)
= f(theta) + L(delta) + o(norm(delta))
```

对于欧氏空间中的标量函数，这个线性映射就是：

```text
L(delta) = grad f(theta) dot delta
```

于是梯度具备两层含义：

1. 它收集了各坐标方向的一阶变化率。
2. 更重要的是，它能统一预测任意微小参数变化 `delta` 带来的函数变化。

第二层含义需要可微性，而不只是各偏导数分别存在。

## 为什么偏导数存在仍可能不可微

偏导数只检查坐标轴方向。一个函数可能在横向和纵向都表现正常，却在斜向出现尖角或不协调变化。

例如定义：

```text
f(x,y) = xy / sqrt(x^2+y^2),  (x,y) != (0,0)
f(0,0) = 0
```

在原点：

- 沿 `x` 轴，函数始终为 `0`，所以 `x` 偏导数为 `0`。
- 沿 `y` 轴，函数也始终为 `0`，所以 `y` 偏导数为 `0`。
- 两个偏导数组成的形式梯度是 `(0,0)`。

但沿对角线 `x=y=t`：

```text
f(t,t) = |t| / sqrt(2)
```

它并没有像梯度 `(0,0)` 预测的那样，以更高阶的小量接近 `0`。所以两个坐标偏导数虽然存在，函数在原点仍不可微。

逻辑关系应记为：

```text
可微
  => 所有偏导数存在
  => 梯度可以被写出来

所有偏导数存在
  !=> 一定可微
```

甚至“所有方向导数存在”本身仍不足以保证可微；这些方向导数还必须彼此协调，能够组成同一个线性映射。

## 为什么机器学习常说“可导”

机器学习工程里，“这个操作可导”通常不是严格区分数学术语，而是在表达：

```text
这个操作存在框架能够使用的梯度规则，
并且梯度可以沿计算图继续传播。
```

因此工程口语中的“可导”经常实际指“可以参与自动微分”。严谨讨论多参数损失的局部线性近似时，使用“可微”更准确。

还要区分“处处可微”和“几乎处处可微”。例如 ReLU：

```text
ReLU(x) = max(0,x)
```

它在 `x=0` 严格不可导，但深度学习框架可以人为约定该点的梯度，例如取 `0`。单个特殊点通常不妨碍整体训练，但离散采样、字符串解析等操作造成的是更根本的梯度路径中断。

## 不可微奖励为什么仍能训练策略

大模型强化学习经常经过：

```text
Policy参数
  -> Token概率
  -> 离散Token采样
  -> JSON/函数调用解析
  -> F1、格式检查、单元测试
  -> reward
```

奖励可能由离散规则产生，无法直接计算：

```text
partial reward / partial theta
```

因此不能直接对奖励执行普通反向传播。但策略梯度使用恒等关系，把期望奖励的梯度改写为对数概率梯度：

```text
grad_theta E[R]
= E[R * grad_theta log pi_theta(a|s)]
```

实际训练常最小化代理损失：

```text
loss = -advantage * log pi_theta(a|s)
```

其中：

- `reward` 或 `advantage` 只是一个数值权重，本身不需要可微。
- `log pi_theta(a|s)` 对模型参数可微。
- 梯度通过对数概率返回 Policy，而不是穿过 JSON 解析或 F1 计算。

这也是 PPO、GRPO 等方法可以使用规则奖励、程序验证器和离散业务指标的基础。相关训练结构见 [[llm-ppo-dpo-grpo-comparison]] 和 [[ppo-critic-td-error-gae]]。

## 最终记忆

```text
偏导数：只改变一个参数，看这个坐标方向的斜率。

方向导数：沿指定方向同时改变参数，看该方向的斜率。

可微：存在同一个梯度，统一近似所有参数的微小联合变化。

策略梯度：奖励不必可微，通过可微的动作对数概率更新模型。
```
