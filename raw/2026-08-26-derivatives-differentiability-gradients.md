# 可导、可微与梯度的对话笔记

## 原始问题脉络

本次对话围绕以下问题展开：

1. “不可微”和“不可导”是否是一回事？
2. 为什么多元函数的偏导数存在，不一定代表函数可微？
3. 为什么应说“函数可微时，梯度可以描述局部变化”，而不是简单说“函数可导”？
4. 强化学习中的奖励不可微，为什么模型仍然能够训练？

## 对话中形成的理解

用户的阶段性理解是：

> 可导一般是评估一个方向、一个参数；可微一般是指所有参数、所有方向。

进一步修正后，更准确的表述是：

- 偏导数考察只改变某一个坐标参数时的变化率。
- 方向导数考察沿某个指定方向变化时的变化率，该方向可以同时改变多个参数。
- 可微要求存在同一个线性映射，在所有足够小的方向上统一近似函数变化。
- 即使各偏导数都存在，也不保证函数可微；即使所有方向导数都存在，仍不自动保证可微，还需要这些方向变化彼此协调并构成同一个线性近似。

## 一元与多元情形

一元函数中，“在某点可导”和“在该点可微”通常等价。多元函数中，机器学习口语里的“可导”含义容易含混：它有时只是指偏导数存在，有时实际想表达能够正常反向传播。严谨讨论梯度的局部线性近似能力时，应使用“可微”。

多元可微的核心近似是：

```text
f(theta + delta)
= f(theta) + grad f(theta) dot delta + o(norm(delta))
```

它表示当参数发生任意足够小的联合变化时，梯度都能够预测函数的一阶变化。

## 强化学习中的不可微奖励

大模型强化学习可能包含如下流程：

```text
模型参数
  -> Token概率
  -> 离散采样
  -> 字符串或JSON解析
  -> F1、格式检查或程序验证
  -> reward
```

离散采样、`argmax`、字符串解析、集合匹配和规则判断通常不能提供从奖励回到模型参数的普通反向传播路径，因此不能直接执行 `reward.backward()`。

策略梯度通过对数概率建立可微代理目标：

```text
loss = -advantage * log pi_theta(action | state)
```

奖励或 Advantage 作为数值权重，不需要自身对模型参数可微；梯度通过可微的 `log pi_theta` 返回模型。
